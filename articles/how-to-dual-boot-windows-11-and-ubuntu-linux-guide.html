How to Dual Boot Windows 11 and Ubuntu Linux Safely (Step-by-Step)

The Best of Both Worlds: Windows 11 for Gaming, Linux for Dev

Dual booting lets you run Windows 11 (for Microsoft Office, games, and proprietary apps) and Ubuntu Linux 24.04 LTS (for software development, AI, and privacy) on the exact same computer with zero performance loss. Every time you turn on your PC, a clean GRUB boot menu allows you to choose your operating system.

The 6-Step Dual Boot Blueprint

  1. Backup Your Data: Always back up your important Windows files to an external drive or cloud storage before altering disk partitions.
  2. Shrink Windows Partition in Disk Management: Right-click Start > Disk Management. Right-click your C: drive > select Shrink Volume. Enter 80,000 MB (80GB) or more. Click Shrink. Leave the resulting space as black 'Unallocated Space'.
  3. Disable Windows Fast Startup: Open Control Panel > Power Options > 'Choose what the power buttons do' > uncheck 'Turn on fast startup'. This prevents Windows from locking disk partitions in a hibernated state.
  4. Flash Ubuntu ISO with Rufus: Download the Ubuntu 24.04 LTS ISO. In Rufus, select your USB flash drive (8GB+), choose Partition Scheme GPT, and Target System UEFI.
  5. Boot USB & Select 'Install Alongside Windows': Restart PC and press your boot menu key (F12 on Lenovo/Dell, F11 on MSI, F8 on ASUS). Select your UEFI USB. Choose 'Install Ubuntu alongside Windows Boot Manager'.
  6. Reboot into GRUB: When finished, remove the USB drive. Your PC will now present the GRUB bootloader on every power-up.

Frequently Asked Questions

Q. Will dual booting delete my Windows files or games?

No. As long as you install Ubuntu into the separate unallocated space created in Step 2, your Windows 11 installation and files remain completely untouched.

Q. Can Ubuntu read files stored on my Windows drive?

Yes! Ubuntu natively mounts Windows NTFS drives, allowing you to access photos, music, and documents stored in Windows directly from Linux.

Q. What if I want to remove Ubuntu later?

Simply boot into Windows 11, open Disk Management, delete the Linux partition, and extend your C: drive back over the space.
