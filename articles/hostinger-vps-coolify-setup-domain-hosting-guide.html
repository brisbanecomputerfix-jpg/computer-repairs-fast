How to Setup Coolify on Hostinger VPS: Deploy Apps & Free SSL

Host Your Own Cloud Platform with Coolify on Hostinger

Why pay expensive monthly fees to Vercel, Heroku, or AWS when you can self-host an unlimited number of websites, Node.js/Next.js apps, WordPress sites, and PostgreSQL databases on a Hostinger KVM VPS using Coolify? Coolify provides a beautiful web dashboard that connects directly to GitHub and handles automatic Docker builds and free Let's Encrypt SSL certificates.

Step-by-Step Installation on Hostinger VPS

  1. Order a KVM VPS: Select a Hostinger KVM 2 or KVM 4 VPS (minimum 4GB to 8GB RAM for smooth Docker builds). Choose the Sydney, Australia datacenter for lowest local latency.
  2. Select the Coolify OS Image: In Hostinger hPanel > Operating System, select the 1-click Coolify (Ubuntu 24.04) template. (Alternatively, install via SSH with curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash).
  3. Access Dashboard: Navigate to http://YOUR_VPS_IP:8000 in your browser and register your admin account.
  4. Attach Your Custom Domain: Point an A record (e.g. coolify.yourdomain.com) to your VPS IP in DNS. Coolify automatically issues an SSL certificate.
  5. Deploy Apps: Click '+ Create Resource' > connect your GitHub repository. Every time you push code to GitHub, Coolify builds and deploys your container automatically.

Frequently Asked Questions

Q. Why shouldn't I host my primary business email on a VPS?

VPS IP addresses are frequently flagged by aggressive spam filters at Microsoft and Google, and most VPS providers block outbound Port 25. Route your email through Google Workspace or Cloudflare Email Routing instead.

Q. Can Coolify manage multiple client domains on one VPS?

Yes! Coolify's built-in Traefik reverse proxy routes traffic for dozens of different domain names to their respective Docker containers on a single VPS.

Q. How do I back up my Coolify databases?

Coolify includes an automated backup scheduler that dumps PostgreSQL and MySQL databases directly to S3-compatible cloud storage (such as Cloudflare R2 or Backblaze B2) nightly.
